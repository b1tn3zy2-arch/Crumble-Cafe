# Crumble Cafe

Одностраничный сайт меню для кафе. Весь контент генерируется через JavaScript-модули, вкладки переключаются без перезагрузки страницы.

## Как запустить

```bash
npm install
npm start
```

После запуска откроется http://localhost:8080

Для сборки в папку `dist/`:

```bash
npm run build
```

## Структура проекта

```
my-cafe/
├── src/
│   ├── index.js          — точка входа, навигация
│   ├── index.html        — HTML-шаблон
│   ├── style.css         — стили
│   ├── home.js           — вкладка «Главная»
│   ├── menu.js           — вкладка «Меню»
│   ├── contact.js        — вкладка «Контакты»
│   ├── menu-data.json    — данные блюд
│   └── images/           — картинки блюд
├── dist/                 — собранный проект (создаётся автоматически)
├── webpack.config.js
└── package.json
```

## Выполненные задания

### Уровень 1. Базовые доработки

- [x] **1.1. Вкладка «Контакты»** — создан `src/contact.js` с функцией `loadContact()`. Выводится адрес, телефон, часы работы и ссылка на соцсеть. Кнопка «Контакты» добавлена в навигацию.
- [x] **1.2. Стилизация через CSS** — в `src/style.css` задан фоновый цвет `body`, стили для кнопок навигации с hover-эффектом, заголовок `h1` со шрифтом Pacifico (подключён через `@import` Google Fonts).
- [x] **1.3. Активная вкладка** — при клике на кнопку ей добавляется класс `.active`, у остальных он убирается. В CSS для `.active` задан жирный шрифт, подчёркивание и другой фон.

### Уровень 2. Работа с контентом и данными

- [x] **2.1. Данные меню в JSON** — создан `src/menu-data.json` со списком блюд (название, цена, описание). Импортируется в `menu.js`, карточки генерируются через `forEach`.
- [x] **2.2. Изображения блюд** — 3 картинки лежат в `src/images/`, импортируются в `menu.js` и вставляются в `<img>`. В `webpack.config.js` настроен `asset/resource` для `.png/.svg/.jpg/.jpeg/.gif`.
- [x] **2.3. Кнопка «Забронировать столик»** — на вкладке «Контакты». По клику показывается `alert('Столик забронирован! Мы вам перезвоним.')`.

### Уровень 3. Интерактивность и UX

- [x] **3.1. Форма обратной связи с валидацией** — на вкладке «Контакты» есть поля «Имя», «Email», «Сообщение» и кнопка «Отправить». Валидация:
  - Имя — минимум 2 символа;
  - Email — проверка регулярным выражением;
  - Сообщение — не пустое.
  
  При ошибке поле подсвечивается красной рамкой и выводится `alert`. При успехе — `alert('Спасибо, ' + name + '!')` и очистка формы.
- [x] **3.2. Счётчик посещений вкладки «Меню»** — используется `localStorage` (ключ `menuCount`). На вкладке выводится «Вы открывали это меню N раз». Счётчик сохраняется после перезагрузки страницы.
- [x] **3.3. Плавная анимация переключения вкладок** — в CSS добавлена `@keyframes fadeIn` и применена к `#content > div` с `animation: fadeIn 0.3s ease-in`. Контент появляется плавно.
